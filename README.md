# أرض الجوال

متجر إلكتروني عربي باتجاه RTL لعرض الجوالات وملحقاتها.

## دورة الشراء
- لا يوجد تسجيل دخول أو إنشاء حساب للمشتري.
- السلة محفوظة في `localStorage` داخل المتصفح الحالي.
- `/checkout/store`: بيانات العميل والعنوان وخيار التقسيط والموافقة على السياسات.
- عند إرسال بيانات التوصيل، يرسل الموقع طلبًا إلى `POST /api/orders`؛ يتحقق الخادم من المنتجات والأسعار من كتالوج الخادم، ثم يحفظ الطلب في MongoDB ويرسل إشعارًا إلى Telegram Admin إذا كانت متغيرات البيئة متاحة.
- `/checkout/payment`: تعرض رقم الطلب والمبلغ وواجهة تمهيدية للدفع. بوابة الدفع الفعلية غير مربوطة بعد، ولا يُخصم أي مبلغ.
- `/policies`: صفحة توضيحية مؤقتة تنتظر نص سياسة الضمان والاسترجاع والتوصيل المعتمد.
- `/api/telegram/webhook`: Webhook محمي برمز سري، يتيح للإداري عرض الطلبات وإضافة طلب يدوي وتغيير حالة الطلبات.

## بوت الإدارة
الأوامر والأزرار الأولية:
- **طلبات العملاء:** عرض آخر الطلبات.
- **إضافة طلب:** إدخال اسم العميل والجوال والعنوان والمنتجات والإجمالي عبر خطوات.
- **تعديل الطلبات:** اختيار طلب وتحديث حالته.
- يتم التحقق من `TELEGRAM_ADMIN_ID` لكل رسالة وتفاعل؛ بقية المستخدمين لا يحصلون على أوامر الإدارة.

## متغيرات البيئة
أضفها إلى إعدادات مشروع Vercel من دون حفظ القيم داخل GitHub:
- `MONGODB_URI`
- `MONGODB_DB=erd_algwal`
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_ADMIN_ID=5569918211`
- `TELEGRAM_WEBHOOK_SECRET` — قيمة عشوائية خاصة بـWebhook، وليست Bot Token.
- `TELEGRAM_WEBHOOK_URL` — رابط HTTPS المنشور والمنتهي بـ`/api/telegram/webhook`.

بعد نشر نسخة تتضمن المسار، يمكن تسجيل Webhook باستخدام:
```bash
npm run telegram:set-webhook
```
ويجب توفير `TELEGRAM_BOT_TOKEN` و`TELEGRAM_WEBHOOK_SECRET` و`TELEGRAM_WEBHOOK_URL` للبيئة التي يُشغّل منها الأمر. السكربت لا يطبع التوكن.

## حدود النسخة الحالية
- أسماء المنتجات والأسعار والصور في `lib/products.ts` تجريبية؛ API الطلبات يستخدم أسعار هذا الكتالوج للتحقق بدل أسعار يرسلها المتصفح.
- تحرير الأقسام والمنتجات من البوت وربط كتالوج MongoDB ما زالا غير منفذين.
- لا توجد بوابة دفع أو مزود تقسيط مربوط.
- إشعار الطلب يتطلب إعداد Telegram، وحفظ الطلب يتطلب اتصال MongoDB صحيحًا.
- بيانات المناطق والمدن مقتبسة من Saudi National Address Open Dataset؛ التفاصيل في `data/SAUDI_ADDRESS_DATA.md`.

## التشغيل
```bash
npm install
npm run dev
```

لم يتم نشر المشروع على Vercel من هذا العمل.
