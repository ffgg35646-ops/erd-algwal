# أرض الجوال

متجر إلكتروني عربي باتجاه RTL لعرض الجوالات وملحقاتها.

## دورة الشراء المبدئية
- لا يوجد تسجيل دخول أو إنشاء حساب للمشتري.
- السلة محفوظة في `localStorage` داخل المتصفح الحالي.
- `/checkout/store`: بيانات العميل وعنوان التوصيل، المناطق السعودية، اختيار التقسيط، والموافقة على السياسات.
- `/checkout/payment`: صفحة طرق الدفع مع ملخص المبلغ وواجهة توضيحية لتكامل بوابة دفع آمنة.
- `/policies`: مكان مخصص لسياسة الضمان والاسترجاع والتوصيل المعتمدة.
- `/checkout` يحوّل إلى خطوة بيانات التوصيل.

## بيانات تجريبية وحدود النسخة الحالية
- المنتجات والصور والأسعار في `lib/products.ts` بيانات تجريبية.
- بيانات التوصيل وخيار التقسيط ومسودة الطلب محفوظة محليًا فقط؛ لا يُنشأ طلب شراء فعلي في قاعدة بيانات حتى الآن.
- بوابة الدفع غير مربوطة. لا تجمع الواجهة رقم بطاقة أو CVV ولا تحفظهما؛ عند اختيار مزود الدفع يجب إدخال بيانات البطاقة من خلال صفحة المزود أو حقوله الآمنة.
- ربط MongoDB وبوت تيليجرام وإرسال الطلبات وإدارة الأقسام والمنتجات لم يُنفّذ بعد.
- تكلفة الشحن وخيارات التقسيط والسياسات النهائية تحتاج اعتماد صاحب المتجر.
- بيانات المناطق والمدن مقتبسة من Saudi National Address Open Dataset؛ تفاصيل المصدر في `data/SAUDI_ADDRESS_DATA.md`.
