# أرض الجوال

متجر إلكتروني عربي باتجاه RTL لعرض الجوالات وملحقاتها.

## النسخة المبدئية
- واجهة متجر بدون تسجيل دخول أو إنشاء حساب.
- أقسام وبطاقات منتجات وصفحة تفاصيل المنتج.
- سلة تحفظ محتوياتها في `localStorage` داخل المتصفح الحالي، وتبقى بعد إغلاق المتصفح وإعادة فتحه.
- السلة منفصلة بين المتصفحات وملفات المستخدم المختلفة.
- صفحة بيانات توصيل قابلة للوصول من السلة عبر `/checkout/store`.
- قائمة بالمناطق الإدارية السعودية الـ13، وقائمة بحث للمدن والمحافظات مرتبطة بالمنطقة المحددة.
- بيانات المناطق والمدن مقتبسة من Saudi National Address Open Dataset؛ تفاصيل المصدر والترخيص في `data/SAUDI_ADDRESS_DATA.md`.

## بيانات تجريبية وحدود النسخة الحالية
- أسماء المنتجات وأسعارها وصورها في `lib/products.ts` بيانات تجريبية للتصميم.
- نموذج بيانات التوصيل يحفظ مسودة محلية في متصفح العميل، ولا ينشئ طلب شراء حقيقيًا بعد.
- ربط MongoDB وبوت تيليجرام، وإرسال الطلبات، وإدارة الأقسام والمنتجات من البوت لم تُنفذ بعد.
- تكلفة الشحن وطريقة الدفع لم يتم تحديدهما في هذه المرحلة.

## التشغيل

```bash
npm install
npm run dev
```
