# أرض الجوال

متجر إلكتروني عربي باتجاه RTL لعرض الجوالات وملحقاتها، بتصميم بسيط مستوحى من متاجر Apple.

## بوت تيليجرام
قائمة الإدارة:
- **طلبات العملاء:** تعرض آخر الطلبات غير المقروءة أولًا، مع عدّاد بجانب الزر وعدّاد متجدد بعد مشاهدة القائمة.
- **إضافة طلب:** إنشاء قسم/تصنيف جديد بالاسم فقط.
- **تعديل الطلب:** اختيار قسم وتغيير اسمه فقط.
- **إضافة منتج:** اختيار القسم، الاسم، الألوان، مساحات التخزين، السعر، التفاصيل، ثم إرسال حتى 10 صور والضغط على «حفظ المنتج».
- **تعديل المنتج:** اختيار منتج وتعديل القسم أو الاسم أو الألوان أو التخزين أو السعر أو التفاصيل أو الصور، مع خيار حذف المنتج وتأكيد الحذف وزر رجوع للقائمة الرئيسية.
- **الاتصال:** إدخال أو تغيير رقم واتساب الدعم؛ يظهر رابط WhatsApp في زر عائم بالموقع.
- تتم حماية أوامر الإدارة بمعرّف `TELEGRAM_ADMIN_ID`، كما يقبل الـWebhook الرسائل الخاصة فقط.

## الكتالوج والتحميل في الخلفية
- الأقسام تُقرأ من مجموعة `categories`، والمنتجات الجديدة من مجموعة `products` في MongoDB.
- الصور المرسلة عبر Telegram تُخزّن كـ file IDs وتُعرض من خلال API خادم لا يكشف Bot Token.
- صفحة المتجر لا تنتظر الكتالوج أو إعدادات واتساب حتى ترسم الواجهة؛ تظهر البيانات المتاحة ثم تجلب أحدث البيانات في الخلفية، وتعيد تحديث الكتالوج كل 30 ثانية وعند التركيز على الصفحة.
- البحث لحظي أثناء الكتابة ويمتد إلى اسم المنتج والقسم والوصف والسعر واللون وسعة التخزين والمواصفات، مع تطبيع اختلافات الحروف والأرقام العربية.
- سلة المشتريات تبقى في `localStorage` للمتصفح الحالي؛ مسودة بيانات التوصيل تستخدم `sessionStorage`.

## دورة الشراء
- لا يوجد تسجيل دخول أو إنشاء حساب للمشتري.
- بيانات التوصيل تُرسل إلى `POST /api/orders`، ويتحقق الخادم من الأسعار من كتالوج الخادم، ثم يحفظ الطلب في MongoDB ويرسل إشعارًا إلى Telegram Admin.
- `/checkout/payment` صفحة تمهيدية فقط؛ بوابة الدفع الفعلية غير مربوطة بعد ولا يتم خصم أي مبلغ.
- `/policies` صفحة مؤقتة تنتظر سياسة الضمان والاسترجاع والتوصيل المعتمدة.

## متغيرات البيئة
أضف القيم في إعدادات الاستضافة فقط؛ لا تحفظ أسرارًا حقيقية في GitHub:
- `MONGODB_URI`
- `MONGODB_DB=erd_algwal`
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_ADMIN_ID=5569918211`
- `TELEGRAM_WEBHOOK_SECRET`
- `TELEGRAM_WEBHOOK_URL` — رابط HTTPS المنشور وينتهي بـ `/api/telegram/webhook`.

بعد نشر المسار على الاستضافة، يمكن تسجيل Webhook من بيئة آمنة باستخدام:
```bash
npm run telegram:set-webhook
```

## حدود النسخة الحالية
- بيانات المنتجات القديمة في `lib/products.ts` تجريبية، ويمكن تعديل المنتجات التي أُنشئت من البوت.
- لا توجد بوابة دفع أو مزود تقسيط مربوط.
- رقم واتساب لن يظهر على أنه رابط صالح إلا بعد إدخاله من زر «الاتصال» في البوت.
- إعداد متغيرات البيئة وتسجيل Webhook واختبار الاتصال الحي ينتظر إعداد الاستضافة الذي يتحكم به صاحب المشروع.
- لم يتم نشر المشروع على Vercel ضمن هذه التعديلات.
