# أرض الجوال

متجر إلكتروني عربي باتجاه RTL لعرض الجوالات وملحقاتها.

## دورة الشراء
- لا يوجد تسجيل دخول أو إنشاء حساب للمشتري.
- السلة محفوظة في `localStorage` داخل المتصفح الحالي. مسودة بيانات التوصيل تستخدم `sessionStorage` فقط خلال جلسة التصفح، لتجنب بقاء بيانات الاتصال والعنوان محفوظة بشكل دائم على الجهاز.
- `/checkout/store`: بيانات العميل والعنوان وخيار التقسيط والموافقة على السياسات.
- عند إرسال بيانات التوصيل، يرسل الموقع طلبًا إلى `POST /api/orders`؛ يتحقق الخادم من المنتجات والأسعار من كتالوج الخادم، ثم يحفظ الطلب في MongoDB ويرسل إشعارًا إلى Telegram Admin إذا كانت متغيرات البيئة متاحة.
- `/checkout/payment`: تعرض رقم الطلب والمبلغ وواجهة تمهيدية للدفع. بوابة الدفع الفعلية غير مربوطة بعد، ولا يُخصم أي مبلغ.
- `/policies`: صفحة مؤقتة تنتظر نص سياسة الضمان والاسترجاع والتوصيل المعتمد.

## بوت تيليجرام
القائمة الإدارية:
- **طلبات العملاء:** عرض آخر 10 طلبات. يوجد رقم بجانب الزر للطلبات الجديدة غير المقروءة؛ عند فتح القائمة تُعلَّم الطلبات المعروضة بأنها شوهدت.
- **إضافة طلب:** بحسب التصميم الحالي، تُدخل اسم القسم/الطلب فقط؛ الاسم يُحفظ كقسم يستطيع صاحب المتجر ربط المنتجات به.
- **تعديل الطلب:** اختيار قسم وتغيير اسمه فقط، وتُحدّث أسماء القسم في المنتجات المرتبطة.
- **إضافة منتج:** اختيار قسم، ثم إدخال اسم المنتج، والألوان المتاحة، ومساحات التخزين، والسعر، والتفاصيل، ثم إرسال صورة واحدة أو عدة صور من تيليجرام والضغط على **حفظ المنتج**.
- **حالات طلبات العملاء:** يمكن تغيير الحالة من أزرار الطلب داخل قسم طلبات العملاء.
- يتم التحقق من `TELEGRAM_ADMIN_ID` لكل رسالة وتفاعل؛ بقية المستخدمين لا يحصلون على أوامر الإدارة.
- صورة المنتج تُخزّن كـ Telegram file ID في MongoDB وتُعرض على الموقع عبر مسار خادم لا يكشف Bot Token.

## انعكاس تغييرات البوت على الموقع
- الأقسام تُقرأ من مجموعة `categories` في MongoDB.
- المنتجات الجديدة تُقرأ من مجموعة `products` في MongoDB.
- الواجهة تعيد تحميل كتالوجها كل 30 ثانية؛ يمكن للعميل أيضًا تحديث الصفحة لرؤية الإضافة الجديدة.

## متغيرات البيئة
أضفها إلى إعدادات مشروع Vercel من دون حفظ القيم داخل GitHub:
- `MONGODB_URI`
- `MONGODB_DB=erd_algwal`
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_ADMIN_ID=5569918211`
- `TELEGRAM_WEBHOOK_SECRET` — قيمة عشوائية خاصة بالـWebhook، وليست Bot Token.
- `TELEGRAM_WEBHOOK_URL` — رابط HTTPS المنشور والمنتهي بـ`/api/telegram/webhook`.

بعد نشر نسخة تتضمن المسار، يمكن تسجيل Webhook من بيئة محلية أو آمنة تملك المتغيرات المطلوبة باستخدام:
```bash
npm run telegram:set-webhook
```

## حدود النسخة الحالية
- أسماء المنتجات وأسعار وصور المنتجات القديمة في `lib/products.ts` تجريبية.
- الطلبات الجديدة تحفظ في MongoDB قبل الانتقال إلى صفحة الدفع.
- لا توجد بوابة دفع أو مزود تقسيط مربوط.
- ربط حساب Vercel ومتغيرات بيئته وتسجيل Webhook الفعلي وإجراء اختبار من تيليجرام لم تكتمل بعد.
- بيانات المناطق والمدن مقتبسة من Saudi National Address Open Dataset؛ التفاصيل في `data/SAUDI_ADDRESS_DATA.md`.

